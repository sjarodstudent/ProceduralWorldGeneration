## Project Description
This project is a terrain generator using Perlin Noise to create procedural landscapes, castles and trees. It is developed in C++ and blueprints. We use Unreal Engine.

## C++ Files
### PerlinNoiseTerrainGenerator.cpp
This file contains the implementation of the `APerlinNoiseTerrainGenerator` class, which is responsible for generating the terrain and associated objects. Here is an overview of the main functions:

- **GenerateTerrain(int StartX, int StartY)**: Generates the terrain from the starting coordinates.
- **GenerateNeighboorTerrain()**: Generates neighboring terrains to create continuity.
- **GeneratePerlinNoiseTexture(int StartX, int StartY)**: Generates a Perlin noise texture for the terrain.
- **LerpPixelColor(int x, int y, float NormalizedHeight, uint8\* Data)**: Interpolates pixel colors based on the normalized height.
- **GenerateCastlePoint(int StartX, int StartY)**: Generates points to place castles on the terrain.
- **GenerateTreePoints(int StartX, int StartY)**: Generates points to place trees on the terrain.
- **IsPointValidForTree(const FVector& Point, float MinDistance)**: Checks if a point is valid for placing a tree based on the minimum distance.

### CastleGenerator.cpp

This file contains the implementation of the ACastleGenerator class, which is responsible for generating a castle structure with outer walls, a dungeon, and a center area. Here is an overview of the main functions:
-	**GenerateOutWalls()**: Generates the outer walls of the castle. It places walls and corners at specific positions based on the OutWidth and OutDepth properties.
-	**GenerateCenter()**: Generates the center of the castle, which includes the dungeon columns. It places floors, walls, and roofs based on the height values generated by the Perlin noise.
-	**GeneratePerlinNoiseDungeon()**: Generates the dungeon layout using Perlin noise. It creates a grid of height values that determine the structure of the dungeon.
-	**GenerateSize()**: Randomly generates the size of the castle by setting the OutDepth and OutWidth properties.
-	**SpawnMesh(UStaticMesh mesh, float X, float Y, float Z, float rotZ, bool ApplyNormal)**: Spawns a static mesh at the specified location with the given rotation. It also adjusts the mesh's position based on a line trace to ensure it is placed correctly in the world.
